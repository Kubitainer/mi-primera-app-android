# Mi Primera App con Android Studio

Práctica 1 de la asignatura **Programacion multimedia y dispositivos moviles** — FP DAM.

## Descripción

Aplicación desarrollada siguiendo el [tutorial oficial de Android Developers](https://developer.android.com/training/basics/firstapp), como primer contacto con Android Studio.

La app recoge un mensaje introducido por el usuario y lo muestra en una nueva pantalla (Activity) al pulsar un botón.

## Tecnologías

- Android Studio
- Java
- Android SDK

## Cómo ejecutarlo

1. Clona el repositorio:
```bash
   git clone https://github.com/Kubitainer/mi-primera-app-android.git
```
2. Ábrelo con Android Studio
3. Ejecuta en un emulador (AVD) o en un dispositivo físico con depuración USB activada

## Pruebas realizadas

- Ejecutado en dispositivo físico
- Ejecutado en emulador virtualizado
